# French Atelier · WhatsApp Batch of 8 (Content brief WA-8-new-Briefs)

Weekly WhatsApp drip series for **French Atelier by Acadomia**, built to spec from the CEO content brief.

- **8 WhatsApp messages** · 6 pure content + 2 promo weeks
- **WA-3** carries the 20% October promo (200 Years of Photography, CTA button `Claim it now`)
- **WA-4** carries the 20% November promo (Novembre Numérique, CTA button `Claim it now`)
- Every message **150–200 words**, exactly **3 useful French words**, one fun fact, calm supportive tone
- **No em dashes, no en dashes, no AI language, no urgency, no Julien / AI Agent / Self Service references, no videos referenced**
- **8 hero images at exactly 1792×897** per brief
- All CTAs route to [www.frenchatelierlive.com](https://www.frenchatelierlive.com)

## Structure

